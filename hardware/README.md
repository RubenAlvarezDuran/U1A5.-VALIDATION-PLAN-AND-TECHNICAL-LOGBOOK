# Hardware

Place hardware-related files in this folder, for example:
- Wiring diagrams
- Block diagrams
- Schematics
- PCB files
- Mechanical drawings
- Component datasheets

Current architecture: ESP32-S3 + 3 x A4988 + 3 x NEMA 17 + 3 limit switches + 12 V electromagnet + MOSFET driver + 12 V / 6 A supply.
